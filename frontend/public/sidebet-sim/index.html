SideBet

Peer‑to‑peer, skill‑based prediction market. One person proposes a wager, another accepts it, and once the outcome is known, the platform settles it. This is a working simulation of that create → accept → settle loop, running against an in‑browser ledger.

Open board
This simulation implements the create → accept → settle lifecycle from the SideBet spec: every balance change is paired with a ledger row (LOCK on create/accept, PAYOUT on settle). Two fixes vs. the as‑built spec: stakes/payouts are derived from what the creator actually enters instead of hardcoded $100/$200 constants, and settlement requires both players to agree on the same winner (mirroring the mutual‑agreement pattern from the production build) rather than one side unilaterally declaring the result.
